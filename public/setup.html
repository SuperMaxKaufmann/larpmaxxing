Source setup.

Paste emails to start immediately. Account connections use this app’s local, read-only MCP tools backed by official APIs. Each person supplies their own authorization.

Gmail

  1. Enable the Gmail API in your Google Cloud project. Configure the consent screen and add yourself as a test user where required.
  2. Create a Desktop OAuth client. Set GOOGLE_CLIENT_ID and, where issued, GOOGLE_CLIENT_SECRET in the server environment. Restart the app.
  3. In Sources, select Gmail and Connect. Sign in and grant gmail.readonly access. The callback returns to this local app.
  4. Optionally choose a timeframe, then import. No messages are sent or modified.

Without a configured client, the connection dialog accepts an already authorized Gmail read-only access token. Tokens are session-only and may expire. Official Google Desktop OAuth guide ↗

Slack · 1:1 only

  1. Create your own internal Slack app and add user scopes im:read and im:history. Optional users:read allows names in the chat selector; otherwise it shows user IDs.
  2. Install it in your workspace and obtain its human user OAuth token. Your administrator may need to approve access.
  3. In Sources, select Slack, Connect, and paste that token. Bot tokens are rejected.
  4. Choose the 1:1 chats and optional timeframe, then import. Channels and group DMs are excluded and rejected before history retrieval.

Slack requires HTTPS OAuth redirects, so this local HTTP app uses your installed app’s authorized user token rather than offering a nonfunctional sign-in button. Official Slack OAuth guide ↗

What leaves this computer?

Credentials go only to their respective provider. Source imports go from Gmail or Slack to local storage. No message content goes to a model during onboarding. Disconnecting clears the active connection; removing a source deletes saved evidence separately.

Imports are bounded and may be incomplete because of retention, permissions, or rate limits. No live account connection was tested during implementation. See docs/mcp-sources.md in your copy for full details.
